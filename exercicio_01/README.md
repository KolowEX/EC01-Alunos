# EC01 - Alunos - Exercício 1

**Tema:** Cadastro de alunos (CRUD)

**Solução:** Formulário HTML, array de objetos, inclusão, edição e exclusão na tabela.

Abra `index.html` diretamente no navegador ou use o Docker a partir da raiz desta atividade. O código desta pasta não depende de outros exercícios.
